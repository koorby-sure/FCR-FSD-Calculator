# Ателье мира — GitHub Pages

## Сохранения
Прогресс остаётся в браузере пользователя; аккаунты GitHub не используются. На одном браузерном профиле и адресе сайта сохранение общее. Экспорт/импорт находится в путеводителе. Перед сменой домена, браузера или переходом с локального HTML скачайте сохранение. Чистка данных сайта удаляет локальный прогресс.

## Оптимизация
Изображения вынесены из HTML и перекодированы в WebP без потери пикселей (либо сохранены в PNG, если он меньше). Размеры картинок не изменены. Изображения запрашиваются по мере использования экранов. CSS и JavaScript вынесены в отдельные файлы. Имена содержат хеш содержимого, чтобы обновления не конфликтовали с кешем браузера.
Калькулятор, логистические данные и ключи сохранений сохранены. Публикация этого архива автоматически не выполнялась.
